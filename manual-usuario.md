# Manual de Usuario
# NeoVision AR OS

**Versión:** 1.0

---

## 1. Introducción

NeoVision AR OS es un prototipo interactivo de interfaz para gafas inteligentes de realidad aumentada enfocadas en videojuegos.

Este manual explica cómo navegar por el prototipo y cómo utilizar las principales funciones disponibles.

> **Nota:** El sistema presentado es un prototipo desarrollado en Figma. Las funciones mostradas son simulaciones destinadas a demostrar el diseño y la experiencia de usuario.

---

# 2. Requisitos

Para visualizar el prototipo se necesita:

- Una conexión a Internet.
- Un navegador web compatible.
- Acceso al enlace del prototipo de Figma.

Para la demostración en realidad virtual:

- Meta Quest 2.
- Conexión a Internet.
- Navegador web del dispositivo.

---

# 3. Acceso al prototipo

## Paso 1

Abrir el enlace del prototipo de NeoVision AR OS:

> [Agregar aquí el enlace de Figma]

## Paso 2

Esperar a que cargue la pantalla inicial.

## Paso 3

Seleccionar el botón:

**Get Started**

Esto inicia el flujo de configuración del dispositivo.

---

# 4. Pantalla de inicio

La pantalla **Welcome** es el punto de entrada al sistema.

En esta pantalla se muestra:

- Logotipo/nombre de NeoVision AR OS.
- Representación de las gafas inteligentes.
- Botón `Get Started`.

### Acción

Seleccionar:

**Get Started**

para continuar al proceso de emparejamiento.

---

# 5. Emparejamiento del dispositivo

Después de seleccionar `Get Started`, el sistema muestra la pantalla **Pairing**.

Esta pantalla representa el proceso de conexión entre las gafas y el sistema.

Se muestra:

- Estado de Bluetooth.
- Animación de conexión.
- Progreso del emparejamiento.

### Acción

Seguir la interacción mostrada en el prototipo hasta completar la simulación de conexión.

Una vez finalizado el proceso, el usuario puede acceder al Dashboard.

> El proceso de Bluetooth es una simulación y no establece una conexión real.

---

# 6. Dashboard

El **Dashboard** es la pantalla principal de NeoVision AR OS.

Desde aquí se puede acceder a las principales funciones.

El Dashboard muestra:

- Juego activo.
- Estado del dispositivo.
- Gaming Mode.
- Accesos rápidos.

También funciona como punto central de navegación.

---

# 7. AR HUD Preview

La sección **AR HUD Preview** representa la información que podría visualizar el jugador mediante las gafas.

Se muestran elementos como:

### Vida

Indica la cantidad de salud disponible del personaje.

### Escudo

Representa el nivel de protección del personaje.

### Mini mapa

Permite representar la ubicación del jugador y elementos del entorno del juego.

### FPS

Muestra la cantidad de cuadros por segundo.

### Temporizador

Indica el tiempo restante o transcurrido de la partida.

### Crosshair

Representa el punto de referencia utilizado para apuntar.

### Team Voice

Indica el estado de comunicación por voz con el equipo.

> Todos los valores mostrados son simulados.

---

# 8. Notificaciones

La sección **Notifications** permite visualizar diferentes eventos relacionados con el jugador.

Entre ellos:

- Invitaciones de amigos.
- Logros.
- Mensajes.
- Alertas.

Algunas notificaciones incluyen botones de acción:

**Accept**

Aceptar una invitación o solicitud.

**Decline**

Rechazar una invitación o solicitud.

---

# 9. Analytics

La sección **Analytics** permite consultar información relacionada con el rendimiento del jugador.

Se muestran:

- Frecuencia cardíaca.
- Nivel de estrés.
- Fatiga visual.
- Tiempo de sesión.
- Tiempo de reacción.
- Estadísticas diarias.
- Gráfica de rendimiento.

> Los datos biométricos son representativos y no proceden de sensores reales.

---

# 10. Configuración

La sección **Settings** permite personalizar diferentes aspectos de la interfaz.

Entre las opciones disponibles se encuentran:

### HUD Transparency

Permite modificar la transparencia de los elementos del HUD.

### Brightness

Permite ajustar el brillo de la interfaz.

### Notifications

Permite configurar las notificaciones.

### Theme

Permite seleccionar entre diferentes temas visuales.

### Language

Permite seleccionar el idioma de la interfaz.

---

# 11. Comandos de voz

La sección **Voice Commands** representa el asistente de voz del sistema.

La pantalla contiene:

- Botón de micrófono.
- Animación de escucha.
- Forma de onda.
- Comandos sugeridos.

### Uso

1. Seleccionar el botón del micrófono.
2. Esperar la animación de escucha.
3. Seleccionar o visualizar uno de los comandos sugeridos.
4. Continuar con la interacción mostrada por el prototipo.

> La función de voz es simulada y no representa un asistente de voz funcional.

---

# 12. Biblioteca de juegos

La sección **Game Library** permite consultar los videojuegos disponibles.

Cada juego puede mostrar:

- Nombre.
- Imagen.
- Calificación.
- Compatibilidad con AR.
- Acceso para iniciar el juego.

También se pueden identificar juegos recientes y favoritos.

---

# 13. Perfil

La sección **Profile** muestra información del jugador.

Incluye:

- Avatar.
- Nombre de usuario.
- Experiencia (XP).
- Logros.
- Plataformas conectadas.

Esta sección representa la identidad y progreso del usuario dentro del ecosistema NeoVision.

---

# 14. Estado del dispositivo

La sección **Battery & Device Health** permite consultar información relacionada con las gafas.

Se muestra:

- Porcentaje de batería.
- Tiempo estimado restante.
- Estado de componentes.
- Temperatura.
- Versión del firmware.
- Actualización disponible.

> Los valores son simulados y tienen únicamente fines demostrativos.

---

# 15. Menú de navegación

NeoVision AR OS cuenta con una barra de navegación inferior.

Esta permite desplazarse entre las principales secciones del sistema.

Además, existe un **Floating Action Button (FAB)**.

El FAB permite acceder rápidamente a:

- Voice.
- Alerts.
- Settings.
- Battery.

---
